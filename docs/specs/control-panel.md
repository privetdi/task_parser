# Spec Delta

## Purpose

Минимальный интерфейс (HTTP API и веб-страница), чтобы увидеть состояние задач, последние результаты и вручную запустить сбор и отправку писем.

## ADDED Requirements

### Requirement: Состояние задач
Интерфейс SHALL показывать для каждой задачи: название, расписание, время следующего запуска, результат последнего запуска (статус, время, краткий итог, ошибка) и, если задача выполняется, признак выполнения.

#### Scenario: Открытие страницы
- **WHEN** пользователь открывает интерфейс
- **THEN** он видит все задачи с последним статусом и временем следующего автоматического запуска

#### Scenario: Автообновление
- **WHEN** задача завершается, пока страница открыта
- **THEN** её статус обновляется без перезагрузки страницы

### Requirement: Кнопки ручного запуска
Интерфейс SHALL предоставлять кнопки ручного запуска каждой задачи; во время выполнения задачи кнопка SHALL быть недоступна, а при отказе (уже выполняется) SHALL показываться понятное сообщение.

#### Scenario: Нажатие кнопки
- **WHEN** пользователь нажимает «Запустить» у задачи
- **THEN** запуск стартует в фоне, интерфейс не блокируется, в журнале появляется запись

### Requirement: Журнал запусков в интерфейсе
Интерфейс SHALL показывать последние запуски всех задач с статусом, способом запуска, длительностью, итогом и текстом ошибки.

#### Scenario: Просмотр ошибки
- **WHEN** запуск завершился ошибкой
- **THEN** причина читается прямо в журнале без обращения к логам сервера

### Requirement: Последние результаты по курсам
Интерфейс SHALL показывать таблицу актуальных курсов с датой каждого курса, прогресс догрузки истории (до какой даты загружено, сколько валют завершено) и кнопку скачивания текущего Excel-отчёта.

#### Scenario: Догрузка не завершена
- **WHEN** история загружена не полностью
- **THEN** виден прогресс и кнопка продолжения догрузки

### Requirement: Последние результаты по графикам
Интерфейс SHALL показывать найденные графики IEA (название, превью, ссылка на источник) со статусом отправки (отправлен / ожидает / ошибка).

#### Scenario: Новый график отправлен
- **WHEN** график отправлен письмом
- **THEN** в списке он отмечен как отправленный со временем отправки

### Requirement: Секреты не раскрываются
API и интерфейс SHALL NOT возвращать пароли и иные секреты из настроек; допускается показывать режим отправки и адреса получателей.

#### Scenario: Запрос настроек
- **WHEN** клиент запрашивает информацию о конфигурации сервиса
- **THEN** пароль SMTP в ответе отсутствует
