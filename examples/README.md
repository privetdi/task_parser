# Примеры результатов

Получены реальным запуском сервиса (`uv run uvicorn app.main:app`) на живых данных НБ РБ:
загружена история с 2016-07-01 (≈108 тыс. курсов, 84 валюты), затем выполнена отправка отчёта
в режиме «без реальной отправки».

| Файл | Что это |
|---|---|
| `rates_2026-10-22.xlsx` | Excel-отчёт с актуальными курсами: в шапке дата отчёта и число валют, у каждой валюты — дата, к которой относится её курс |
| `email_rates_report.eml` | Письмо, в котором этот отчёт ушёл (открывается любым почтовым клиентом; файл во вложении — тот же) |
| `journal.json` | Журнал запусков: догрузка истории, проверка курсов, отправка отчёта и запуск `iea_charts` |

**Графики IEA.** Скачанных графиков здесь нет: сайт IEA закрыт проверкой Cloudflare и не пускает
автоматизированный браузер. Запуск `iea_charts` в `journal.json` завершился ошибкой с понятной
причиной — это штатное поведение сервиса. Как получить допуск сайта вручную — в основном README,
раздел «Если сайт IEA показывает проверку»; что проверено и что нет — раздел «Что не реализовано».
